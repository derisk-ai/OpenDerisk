# 全片一致性控制策略

长片/多镜头视频最大的质量风险是"镜头间不一致"。本 skill 的一致性由 agent（你）负责，
工具只做机械执行。以下清单在剧本阶段就要落实。

## 视觉一致性

1. **风格锚定**：选定 `assets/styles/` 中一个风格后，全片所有视觉产物（生图、
   动画页面、字幕配色）都从该风格的 `consistency_anchors` 与 `template_injection`
   取值，禁止中途换风格。
2. **色彩预算**：全片主色 1 + 强调色 ≤2 + 背景 1，写进 `plan.md`，
   每镜生成后对照检查。
3. **构图规格统一**：分辨率、主体位置（居中/三分）、留白比例全片一致；
   imageflow 运镜按奇偶推进/拉远交替，避免随机运镜造成跳跃感。
4. **生图一致性**（imageflow/fullvideo）：
   - 每镜 prompt 共用同一 `image_prompt_prefix`（来自风格库）
   - 同一主体跨镜出现时，在 prompt 中重复该主体的完整描述（外观、服装、配色），
     不要用"同上""前面那个角色"这类指代
   - 固定负面词（`image_negative_prompt`），防止风格漂移
5. **动画一致性**（webanim）：全片模板的 `BG1/BG2/ACCENT/ACCENT2` 必须取同一风格的
   注入值；字号比例统一（标题/正文/注释三级）

## 叙事一致性

1. **开头语查重**：各镜旁白开头语不得重复（写作规则已定，完成后自查一遍）
2. **信息递进**：剧本需有明确结构（悬念→展开→结论 或 总→分→总），
   在 `script.md` 中标注每镜的功能位（开场/论点/证据/收尾）
3. **称呼与术语统一**：同一项目名、人名、数字口径（如"15 万"不要一会儿写"150K"）
   全片一致，在剧本阶段建一个术语表写进 `script.md`
4. **时长节奏**：单镜旁白 30~60 字；信息密集镜取下限，情绪镜可放宽到 70 字

## 交付前一致性自查（compose 验证之外的人工项）

- [ ] 抽看首/中/尾三帧，配色与风格是否与选定风格一致
- [ ] 字幕字号在所有镜头一致（由 pv_subs 统一生成，天然满足）
- [ ] 无镜头出现占位素材冒充正式素材（调试产物必须声明）
