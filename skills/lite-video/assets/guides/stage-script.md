# 阶段 1：剧本讨论（script，门控）

> 本文件由 SKILL.md 的阶段 1 入口块引用；进入剧本环节时必读。含 init 后自动启动看板（见 dashboard.md）。


1. **意图讨论**（先于一切）：与用户确认定位（面向谁/想传达什么）、风格
   （严谨/轻松/悬念）、篇幅（分镜数，默认 5~7）、**模式**（见"三模式选择"）。
   用户已在需求里说清的可跳过对应项，合并为一次提问。
2. `pv_db.py init --dir <项目目录> --topic <主题> [--title] [--width 1080 --height 1920]
   [--voice zh-CN-YunxiNeural] [--fps 30] --mode <imageflow|webanim|fullvideo>`
   （横屏则 1920×1080；女声 `zh-CN-XiaoxiaoNeural`；知识类默认男声云希）
2b. **init 成功后立即后台启动预览看板**（硬纪律，让用户能实时见进度/预览/反馈）：

   ```bash
   python3 scripts/pv_dashboard.py --dir <目录> --start
   ```

   - 命令向 stdout 打印一行 `DASHBOARD_URL=http://127.0.0.1:8620/`（端口被占会自动
     避让到 8621..8639，地址相应变化）
   - **取 `DASHBOARD_URL=` 那行的地址，原文告知用户**：「看板已开启：<地址>，
     可在浏览器实时查看流水线进度、预览各镜产出、直接提交反馈」
   - 命令非阻塞（后台运行，日志写项目目录 `.dashboard.log`）；启动失败按报错排查，
     **不阻塞**剧本讨论与生产
   - 会话恢复时同样跑 `--start`（已在运行会自动复用，不重复开端口）；
     停止用 `--stop`，查状态用 `--status`
3. 创作逐镜旁白，规则：
   - 每段 30~60 字（约 6~13 秒语音）；各段**开头语不得重复**；口语化
   - 段末不加标点；段内用中文标点控制停顿（供 TTS 断句）
   - **标点与停顿（默认自动支持）**：逗号=短停、句号/问号/叹号=长停，
     所有 provider 自动按标点断句；piper 另有句间停顿参数（默认 0.35s，
     `tts.yaml` 的 `piper_silence` 或 `--silence` 可调）。想要更松的节奏，
     写旁白时多用短句 + 逗号即可
   - 含英文/数字/符号的镜头要写 `tts_text` 朗读转写（见"关于配音质量"）
   - 事实类主题（榜单/新闻/数据）：先联网检索核实事实，每个事实点记入
     `pv_db.py log --stage script --content "<来源与要点>"`
4. 为每镜写画面描述 `image_prompt`（主体、环境、光线、构图、镜头运动倾向）。
   - webanim 模式：为每镜选定模板（数据→data-chart、榜单→ranking-list、
     观点→text-card、可爱→cute-pop、科技→neon-glow），在剧本中记录模板+数据映射
   - **动画简报 `animation_brief`（webanim 模式每镜必填）**：这是"动画怎么演"
     的正式产物，把内容做得更丰富/更深/更有趣的关键。每镜写清四件事：
     1. **演什么**：核心信息的视觉叙事（如"三个柱子按真实数据比例生长，
        冠军柱加冕金光"），而不只是"展示一个图表"
     2. **怎么演**：从 `assets/guides/webanim-design.md` 的配方里挑 2~3 个
       动效（错峰入场/呼吸/辉光/弹跳…），标注节奏点（第几秒发生什么）
     3. **趣味点**：一个记忆点或彩蛋（如"数字滚动到 152K 时撒彩带粒子"）
     4. **转场钩子**：本镜结尾与下一镜开头的动势衔接
     用户可在剧本批准环节直接修改 `animation_brief` 指导深度与趣味方向
   - fullvideo 模式：额外描述镜头运动与首尾帧构图（起始/落点画面）
5. 产出两个文件：
   - `script.md`：完整剧本（主题、标题、模式、风格、逐镜旁白+画面描述+
     动画简报+功能位标注）
   - `shots.json`：`[{"id":1,"narration":"...","image_prompt":"画面描述",
     "tts_text":"朗读转写(可选)","animation_brief":"动画简报(webanim必填)"}, ...]`
6. `pv_db.py set-shots --dir <目录> --file shots.json` 导入
7. `gate` → 展示剧本 → 等批准
