# 模式选择策略

三种模式的定位与选择决策树，剧本讨论阶段完成决策，`init --mode` 后不可切换。

## 定位对比

| 模式 | 视觉来源 | 依赖 | 速度 | 适用题材 |
|---|---|---|---|---|
| imageflow 图文 | 图片 + Ken Burns 运镜 | 仅需文生图（可占位图兜底） | 最快（分钟级） | 通用解说、资讯、兜底方案 |
| webanim Web动画 | HTML/CSS 动画逐帧渲染 | playwright + chromium | 中（约 7 秒动画/分钟） | 数据图表、榜单、观点卡片、教程 |
| fullvideo 全视频 | agent 自带生图/生视频工具 | 取决于环境工具 | 取决于工具 | 叙事短片、强表现力题材 |

## 决策树

1. 环境有可用的**图生视频**能力（生视频 skill / API / ComfyUI）？
   - 有 → 向用户确认成本与耗时 → **fullvideo**
   - 无 → 下一步
2. 环境有 **playwright + chromium**（运行 `python3 -c "import playwright"` 验证）？
   - 有，且题材含数据/榜单/观点强调 → **webanim**
   - 有，但题材偏实景叙事 → 提示用户 webanim 擅长图形化表达，仍可选
3. 以上都不满足 → **imageflow**（永远可用的兜底）

## 混合使用

同一项目内**不能混用模式**（阶段链不同），但可以：
- webanim 项目中，个别镜头（如实景照片展示）无对应模板时，
  该镜直接用静态图模板（text-card 变体）呈现，不必另起项目
- 系列内容（如月度榜单）建议固定模式 + 固定风格，形成栏目感

## 降级规则（必须向用户如实声明）

- webanim 渲染失败且短时间无法修复 → 征求用户同意后，可降级 imageflow 重新初始化
- fullvideo 的生成工具中途不可用 → 已生成的镜头保留，剩余镜头不得用占位素材冒充，
  应暂停并告知用户
