# 成本登记与预算策略

凡是调用计费服务（生图、生视频、TTS 付费音色、云渲染）的动作，**先估后记**：
生成前向用户报预算，生成后用 `cost-log` 登记实际成本。

## 登记命令

```bash
python3 scripts/pv_db.py cost-log --dir <目录> --stage <阶段> \
  --item "生图x6" --cost 0.24 --currency CNY --notes "即梦 0.04/张"
```

`status` 会自动汇总累计成本；交付报告时必须带上累计成本。

## 免费路径（默认优先）

| 环节 | 免费方案 | 说明 |
|---|---|---|
| 旁白 | edge-tts | 免费，需公网 |
| 动画渲染 | pv_webrender 本地渲染 | 仅耗 CPU 时间 |
| 配图兜底 | pv_placeholder | 免费，仅限调试/兜底 |
| 字幕 | pv_subs | 免费 |

## 计费环节预算参考（数量级，以实际为准）

- 文生图：0.02~0.1 元/张；6 镜视频约 6~12 张
- 图生视频：0.2~1 元/条（按秒计费居多）；6 镜 ≈ 1.2~6 元
- 数字人/高级音色：按分钟计费，单独询价

## 控制规则

1. 剧本批准时就要把**预计总成本区间**写进 `plan.md`
2. 单镜生成失败重试最多 2 次，重试成本也要记入
3. 成本超出计划 50% 时，暂停并向用户报告，获准后继续
4. 用户未授权任何付费服务时，全部走免费路径，占位素材必须声明
