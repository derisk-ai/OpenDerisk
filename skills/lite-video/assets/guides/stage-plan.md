# 阶段 2：制作计划（plan，门控）

> 本文件由 SKILL.md 的阶段 2 入口块引用；进入计划环节时必读。


产出 `plan.md`，按所选模式逐阶段写清：输入、动作、产出、**验证标准**、**预计成本**。

**通用验证标准**（各模式片段/合成阶段）：

| 阶段 | 动作 | 验证标准 |
|---|---|---|
| tts | pv_tts.py 逐镜合成旁白 | 每镜音频存在、时长>0.5s、与 DB 一致（±0.3s） |
| compose | pv_subs.py + pv_concat.py | 成片时长=各镜之和（±1s）、分辨率正确、有音轨、字幕已渲染 |

**模式专属**：

| 模式 | 视觉阶段 | 验证标准 |
|---|---|---|
| imageflow | 文生图→pv_segment.py 图片+运镜 | 图可解码；片段时长对齐（±0.3s）、分辨率正确、SAR=1:1 |
| webanim | pv_template.py 生成页面→pv_weblint.py 预检→pv_webrender.py 渲染 | __seek 契约满足、无违禁调用；片段时长对齐（±0.3s）、分辨率正确、SAR=1:1 |
| fullvideo | agent 生图首尾帧→agent 生视频 | 首帧可解码；片段时长对齐（±0.5s，生成模型波动大）、分辨率正确、SAR=1:1 |

计划中必须包含：选定风格名、每镜视觉方案、成本预估（见 `assets/guides/cost-strategy.md`）。
`gate` → 展示计划 → 等批准。
