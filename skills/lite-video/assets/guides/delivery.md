# 阶段 4：交付 与 断点续做

> 本文件由 SKILL.md 的交付/断点续做入口块引用；进入交付或会话恢复时必读。


读取 `status`，向用户报告：**标题、模式、总时长、分镜数、成片路径、各镜内容概览、
验证结果汇总、累计成本**。用户要调整时（换音色/改文案/重做某镜）：
- 改文案 → 回到对应阶段重跑（脚本都幂等，`--force` / `--shot N` 支持局部重做）
- 状态库自动保持一致，无需手工维护

## 断点续做（会话恢复）

```bash
python3 scripts/pv_db.py --dir <目录> next-stage   # 看当前卡在哪
python3 scripts/pv_db.py --dir <目录> status        # 看全局
```
恢复会话时同步把预览看板拉起（已在运行则自动复用），并再次向用户报地址：

```bash
python3 scripts/pv_dashboard.py --dir <目录> --start
```
所有执行脚本幂等：已完成的镜头自动跳过。`awaiting_human` 状态说明在等用户审批，
把暂存的剧本/计划重新展示给用户即可。
